# Visual Direction Workspace

Status: concept foundation

This directory defines the visual/world-design language for the Starfield overhaul experiments before implementation constraints are allowed to dominate the design.

The purpose is not to lock every asset or planet in advance. It is to establish enough shared visual logic that later Creation Kit, SFSE, procedural-generation, and asset experiments have a clear target.

## Core question

A successful world should answer, at a glance:

> Why does this place exist in this form, and why could it not simply be Earth with a different sky?

The project should preserve grounded human machinery where useful, while making the environments, geology, ecology, weather, spatial composition, and location integration far less familiar.

## Documents

- `00_VISUAL_PHILOSOPHY.md` — overall art direction and visual principles.
- `01_SHAPE_LANGUAGE_AND_ANTI_PATTERNS.md` — silhouette rules and explicit things to avoid.
- `02_HUMAN_ARCHITECTURE_AND_SHIP_SCALE.md` — how built environments respond to alien worlds and low-altitude ship traversal.
- `worlds/` — six reference-world concepts used to stress-test the visual language.

## Reference-world test

The initial six worlds are intentionally dissimilar:

1. **Khepri** — fractured crater moon / flight-first test world.
2. **Pelagos** — dense-atmosphere float biosphere.
3. **Nadir-Tau** — tidally locked terminator world.
4. **Vitria** — silica/crystalline storm world.
5. **Thalassa** — oceanic archipelago world.
6. **Eden-9** — rare genuinely Earth-like biosphere, used as a control case.

These are not final lore names and not commitments to production content. They are visual design laboratories.

## Acceptance rule

If the UI is removed and the six worlds are shown in grayscale screenshots, a viewer should still be able to distinguish them primarily through silhouette, structure, scale, atmosphere, and environmental composition.

If identity depends mainly on color grading, the design is not mature enough.

## Next visual phase

After the written direction is reviewed, each reference world should receive concept-image iterations covering:

- orbital / distant read
- horizon silhouette
- ground traversal view
- ship-scale canyon/approach view
- settlement/POI integration
- close environmental detail

The images should be judged against the written rules, then the documents should be revised rather than treating the first concepts as canon.
