# Planetary World Design Template

Status: reusable visual/physical design framework

## Purpose

Every reference world and future production world should be designed from physical conditions outward rather than from palette, biome labels, or isolated spectacle ideas.

The goal is to make each world feel like a coherent place whose geology, weather, ecology, architecture, traversal, hazards, and visual language all derive from the same small set of environmental causes.

Use this template before concept art is treated as authoritative.

---

# 1. Identity

## Working name

`<world name>`

## One-sentence pitch

Describe the world in one sentence without relying on color words.

## Design role

What does this world prove or contribute to the project?

Examples:

- barren geological benchmark;
- living alien biosphere benchmark;
- weather-driven world;
- rare familiar Earth analogue;
- tidal-locking world;
- ocean world;
- anomaly-affected special case.

## Familiarity target

Choose one:

- familiar;
- familiar process, unfamiliar result;
- structurally alien;
- exceptional/anomalous.

A world should not be pushed toward maximum strangeness simply because it can be.

---

# 2. Planetary physics baseline

## Gravity

- relative surface gravity;
- implications for terrain, structures, organisms, falling material, and flight.

## Atmospheric pressure

- vacuum / tenuous / thin / Earth-like / dense / extreme;
- approximate working pressure if known;
- implications for weather, sound, fluids, aerodynamics, and human protection.

## Atmospheric composition

List major gases or use Starfield's existing environment class until exact chemistry is established.

Do not invent reactive or exotic atmospheres solely for visual novelty without checking whether the resulting chemistry is internally coherent.

## Temperature regime

Record:

- typical surface range;
- day/night variation;
- latitude or altitude differences;
- seasonal variation if relevant.

## Insolation / star characteristics

Record visual and physical implications of:

- star color/type;
- orbital distance;
- tidal locking;
- long day/night cycle;
- multiple stars if relevant.

## Magnetic / radiation environment

Only when it materially affects:

- weather;
- aurora;
- radiation hazard;
- settlement design;
- electronics;
- biology.

---

# 3. Fluids, volatiles, and phase state

Before placing visible liquids, determine whether surface pressure and temperature permit them.

## Stable surface liquids

List only fluids that can plausibly remain liquid in the stated environment.

For each:

- substance;
- stability conditions;
- where it occurs;
- whether it is common or exceptional.

## Ice / solid volatiles

Examples:

- water ice;
- carbon dioxide ice;
- ammonia-bearing ice;
- other lore-compatible volatiles.

Specify where they remain stable.

## Vapor / sublimation

Define whether exposed volatiles produce:

- transient vapor;
- plumes;
- frost cycling;
- geysers;
- seasonal deposition.

## Subsurface fluids

Pressure and geothermal conditions may support liquids that cannot survive at the surface.

Use this deliberately for caves, drilling, mining, cryovolcanism, or hidden ecosystems.

## Hard rule

No unexplained surface fluid exists merely because it looks interesting.

If a visual resembles flowing liquid but is actually mineral deposition, fused material, dust transport, biological film, or another process, state that explicitly.

---

# 4. Dominant geological processes

Choose a small number of processes that visibly shaped the world.

Possible drivers:

- impact cratering;
- volcanism;
- cryovolcanism;
- tectonic faulting;
- aeolian erosion;
- sedimentation;
- glaciation;
- dissolution/karst;
- ocean erosion;
- tidal deformation;
- thermal cracking;
- chemical precipitation;
- collapse/subsidence;
- anomaly-driven alteration where Starfield lore supports it.

## Formation history

Write the major events in chronological order.

A useful target is 3–6 stages.

Each major visual form should ideally point back to one of these stages.

---

# 5. Shape language

## Primary form

The largest repeating silhouette visible from kilometres away.

## Secondary form

Forms that organize travel at regional scale.

## Detail form

Close-range material or erosion language.

## Void form

Caves, canyons, sinkholes, channels, spaces beneath canopies, overhangs, atmospheric gaps, etc.

## Directional bias

Does the world have a preferred orientation created by wind, tide, tectonics, impact geometry, sunlight, slope, current, or growth?

## Grayscale test

The world should remain recognizable without relying on its color palette whenever it is intended to be visually distinctive.

---

# 6. Atmosphere and weather

## Baseline sky state

Define:

- clarity;
- haze;
- cloud structure;
- dominant visibility range;
- direct versus diffuse lighting.

## Weather drivers

Explain why the weather exists.

Examples:

- ocean heat transport;
- strong pressure cells;
- dust availability;
- tidal heating;
- extreme day/night gradient;
- volatile cycle.

## Weather states

Define a small state family rather than unrelated effects.

For each state record:

- visual appearance;
- visibility;
- wind;
- precipitation/particles;
- electrical effects;
- environmental hazard;
- traversal implications;
- ship-flight implications.

## Spatial behavior

Decide whether weather is:

- broadly regional;
- local/cellular;
- a moving front;
- terrain-channeled;
- altitude-dependent.

Do not assume a global weather-state transition is sufficient if the design depends on seeing a storm physically approach.

---

# 7. Ecology

Skip this section for sterile worlds.

## Energy source

Examples:

- direct sunlight;
- diffuse light;
- chemosynthesis;
- geothermal energy;
- atmospheric nutrients;
- tidal ecosystems.

## Environmental constraints

What strongly shapes life?

Examples:

- wind;
- pressure;
- gravity;
- poor visibility;
- drought;
- periodic flooding;
- radiation;
- low light;
- extreme temperature gradient.

## Structural motifs

Choose a limited family of recurring forms shared across organisms.

This prevents procedural life from becoming a collection of unrelated alien props.

## Food/ecological relationships

Define at least a simple causal chain rather than isolated creature spawns.

## Biological visual restraint

State which common sci-fi shortcuts are forbidden for this world.

---

# 8. Human adaptation

Human technology should stay recognizably Starfield-like unless a faction-specific design requires otherwise.

The environment should visibly change how that technology is deployed.

Document adaptations for:

- foundations;
- structural loading;
- radiation/thermal shielding;
- wind exposure;
- drainage;
- corrosion;
- dust/abrasion;
- lightning;
- pressure sealing;
- visibility/navigation;
- landing pads/hangars;
- exterior maintenance;
- resource extraction.

## Placement rule

A generic prefab sitting on an arbitrary flat patch should be treated as a failure unless there is a clear in-world reason.

---

# 9. Ship-scale environment design

Every important world should be assessed from the ship cockpit as well as on foot.

## Flight identity

What makes flying here different?

Examples:

- canyon routing;
- low gravity;
- heavy atmosphere;
- turbulence;
- poor visibility;
- strong crosswind;
- suspended organisms;
- towering geology;
- magnetic/electrical interference.

## Terrain routes

Identify:

- safe corridors;
- risky shortcuts;
- sheltered approaches;
- exposed crossings;
- landmark-guided routes;
- hidden access routes.

## Landing logic

Explain where and why landing infrastructure can exist.

## Combat implications

How does the environment alter:

- line of sight;
- targeting;
- maneuvering;
- cover;
- missile use;
- sensor range;
- escape routes?

---

# 10. Surface/on-foot traversal

Define how the same environment changes walking exploration.

Consider:

- elevation;
- visibility;
- exposure;
- hazards;
- soft/unstable terrain;
- caves;
- verticality;
- weather shelter;
- ecological barriers;
- movement aids.

Ship-scale and on-foot routes should overlap where useful but should not be identical.

---

# 11. POI logic

## Why people came here

Examples:

- mining;
- research;
- settlement;
- strategic position;
- concealment;
- salvage;
- tourism;
- agriculture;
- anomaly study.

## Why this location was selected

Tie POI placement to terrain/environment rather than random procedural availability.

## Environmental state

Document how local conditions can affect:

- damage;
- abandonment;
- access routes;
- defenses;
- power;
- occupants;
- interior layout.

## Repetition rule

If two sites share modules, their geography, function, history, damage state, occupants, and route structure should prevent them from feeling like identical copies.

---

# 12. Signature regions and landmarks

Define 3–6 recognizable subregions.

Each should have:

- a distinct silhouette;
- a physical cause;
- a gameplay purpose;
- a visual relationship to the larger world.

Define at least one landmark that can orient both a walking player and a pilot.

---

# 13. Visual benchmark scene

Specify one concept-art scene that proves the world identity.

Include:

- camera position;
- player/ship scale reference;
- foreground;
- middle distance;
- horizon;
- weather state;
- human structure if relevant;
- what should be understood from the image without explanation.

---

# 14. Visual anti-patterns

List world-specific failure modes.

Examples:

- Earth biome plus recolor;
- giant mushroom shorthand;
- random crystal field;
- ubiquitous emissive life;
- arbitrary floating rocks;
- unexplained surface liquids;
- noisy terrain everywhere;
- generic prefab placement;
- weather used to conceal generic terrain;
- spectacular forms with no physical cause.

---

# 15. Lore compatibility

Classify unusual features as one of:

- ordinary planetary science;
- plausible extrapolation;
- established Starfield technology;
- established Starfield anomaly/lore;
- deliberate new fiction.

Prefer the first four when they can achieve the desired result.

When new fiction is introduced, state clearly why existing lore cannot provide the needed explanation.

---

# 16. Implementation unknowns

Do not silently assume the engine can reproduce the concept.

Record technical questions separately, for example:

- terrain generation limits;
- weather spatialization;
- moving storm fronts;
- ship turbulence;
- flora placement rules;
- suspended/large organisms;
- atmospheric visibility controls;
- cave/worldspace streaming;
- ship-accessible hangars;
- collision/LOD constraints.

These questions feed the capability matrix and experiments rather than weakening the visual target prematurely.

---

# 17. Acceptance tests

A benchmark world should pass as many of these as applicable:

1. **Silhouette test** — recognizable in grayscale.
2. **Physics test** — visible materials/processes are compatible with the environmental baseline.
3. **Cause test** — major visual features have a reason to exist.
4. **Human adaptation test** — settlements visibly respond to the environment.
5. **Flight test** — terrain/weather creates meaningful ship-scale navigation.
6. **On-foot test** — the same environment changes ground traversal.
7. **POI test** — locations appear embedded in the world rather than dropped onto it.
8. **No-palette test** — alienness survives removal of unusual color grading.
9. **No-gimmick test** — removing the most obvious spectacle element does not collapse the world's identity.
10. **Memory test** — a player should be able to describe the world later using structural traits rather than only color or biome labels.
